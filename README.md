# GymStats

Offline-first трекер силовых тренировок и антропометрии на .NET MAUI.

## Возможности

- тренировки с нуля и по шаблонам;
- подходы: вес, повторения, RPE, темп;
- предыдущий результат упражнения прямо при вводе подхода;
- база упражнений с фильтрами по мышечной группе, оборудованию и движению;
- пользовательские упражнения;
- цели шаблонов: подходы, повторы, вес и RPE;
- аналитика тренировок, тоннажа и среднего RPE;
- графики прогресса по упражнению и объёмам;
- графики антропометрии с выбором показателя;
- замеры веса, груди, талии, бёдер, бицепса, бедра, икры и шеи;
- фото и видео прогресса с локальным хранением;
- полный ZIP-бэкап истории и медиа;
- тёмная тема через системную тему;
- Android, iOS, Mac Catalyst и Windows.

## Стек

- .NET 10
- .NET MAUI
- C#
- Entity Framework Core 10
- SQLite
- CommunityToolkit.Mvvm
- xUnit

Данные хранятся локально в SQLite. Интернет приложению для обычной работы не требуется.

## Запуск из Visual Studio

1. Установи Visual Studio 2026 и workload **.NET MAUI**.
2. Склонируй репозиторий или скачай его ZIP-архивом.
3. Открой `GymStats.slnx`.
4. Дождись завершения Restore NuGet-пакетов.
5. В верхней панели Visual Studio выбери проект **GymStats**.
6. Для компьютера выбери **Windows Machine**.
7. Для Android выбери подключённый телефон или Android Emulator.
8. Нажми зелёную кнопку запуска.
9. При первом запуске приложение создаст локальную SQLite-базу автоматически.

Для iOS нужен Mac с установленными Xcode и Apple signing-инфраструктурой.

## Тесты

Запуск unit-тестов:

`dotnet test GymStats.Tests/GymStats.Tests.csproj`

GitHub Actions дополнительно проверяет unit-тесты и Release-сборки Android, Windows и iOS/Mac Catalyst.

## Данные

Перед сменой устройства используй раздел **Резервная копия**. ZIP содержит JSON со структурой данных и найденные локальные фото/видео.

## Архитектура

- `Models` — сущности локальной БД;
- `Data` — SQLite/EF Core и безопасное обновление локальной схемы;
- `ViewModels` — состояние экранов и команды;
- `Services` — аналитика, медиа, бэкап и графики;
- `Resources/Styles` — единая визуальная система.

Приложение спроектировано так, чтобы позже можно было добавить синхронизацию без зависимости текущего офлайн-режима от облака.

# Установка на Android-телефон

Ниже самый простой способ установить готовую Release-версию без Visual Studio.

## Способ 1 — скачать готовый APK из GitHub Actions

### Шаг 1. Открой репозиторий

Открой страницу репозитория GymStats на GitHub и перейди во вкладку **Actions**.

### Шаг 2. Выбери успешную сборку

В списке запусков найди самый свежий запуск **GymStats CI**.

Нужен запуск, у которого общий статус **Success / зелёная галочка**.

**Не скачивай APK из запуска с красным крестиком.** Если последний запуск ещё выполняется, дождись его завершения.

### Шаг 3. Открой страницу запуска

Нажми на название запуска. Откроется страница с четырьмя проверками:

- `tests`
- `build-android`
- `build-windows`
- `build-ios`

Для готового Android-файла главное, чтобы `build-android` завершился успешно.

### Шаг 4. Найди Artifacts

Прокрути страницу запуска **в самый низ**.

Там должен находиться блок **Artifacts**.

В нём будет архив:

**GymStats-Android**

Нажми на него — браузер скачает ZIP-архив.

### Шаг 5. Распакуй архив

На компьютере открой скачанный ZIP.

Внутри находится APK-файл приложения.

Если Windows показывает предупреждение, что архив скачан из интернета, просто распакуй его стандартным архиватором.

### Шаг 6. Перенеси APK на телефон

Самый простой вариант — подключить телефон USB-кабелем.

1. Разблокируй телефон.
2. Подключи USB-кабель.
3. На телефоне выбери режим **Передача файлов / File Transfer**, если появится уведомление о режиме USB.
4. В проводнике Windows открой телефон.
5. Открой папку **Download / Загрузки**.
6. Скопируй туда APK-файл.

Также APK можно передать через Telegram, Google Drive, OneDrive или любой другой удобный способ.

### Шаг 7. Разреши установку APK

Открой на телефоне приложение **Файлы / Files** или файловый менеджер.

Открой папку **Загрузки / Download** и нажми на APK.

Android может показать сообщение примерно такого вида:

**«В целях безопасности вашему телефону запрещено устанавливать неизвестные приложения из этого источника».**

Это нормально для APK, установленного не из Google Play.

Нажми **Настройки** и включи разрешение:

**Разрешить установку приложений из этого источника**

Разрешение нужно дать именно тому приложению, из которого ты открываешь APK — например **Файлы**, **Chrome** или **Telegram**.

После этого вернись назад и снова нажми на APK.

### Шаг 8. Установи приложение

В окне установки нажми **Установить**.

Дождись завершения установки и нажми **Открыть**.

После этого **GymStats** появится в списке обычных приложений телефона.

## Способ 2 — установка через USB и ADB

Этот способ удобен, если на компьютере уже установлен Android SDK Platform Tools.

### На телефоне

1. Открой **Настройки → О телефоне**.
2. Найди **Номер сборки**.
3. Нажми на него несколько раз, пока Android не сообщит, что режим разработчика включён.
4. Вернись в настройки.
5. Открой **Для разработчиков**.
6. Включи **Отладка по USB**.
7. Подключи телефон к компьютеру.
8. Если телефон спросит **«Разрешить отладку по USB для этого компьютера?»**, подтверди.

### На компьютере

Положи APK в папку, где находится `adb`, и выполни:

`adb devices`

В списке должен появиться телефон.

Затем выполни:

`adb install GymStats-*.apk`

Если приложение уже установлено, для обновления можно использовать:

`adb install -r GymStats-*.apk`

После успешной установки приложение можно запускать непосредственно с телефона.

## Если APK не устанавливается

Проверь по порядку:

1. APK скачан полностью и ZIP действительно распакован.
2. Ты запускаешь именно файл с расширением `.apk`, а не ZIP.
3. В Android разрешена установка приложений из источника, через который открыт APK.
4. На телефоне достаточно свободного места.
5. Если это обновление существующей версии, не удаляй приложение без необходимости — так можно потерять локальную базу. Сначала используй встроенную **Резервную копию**.
6. Если Android сообщает о конфликте подписи или пакета, удали старую тестовую версию и установи Release APK заново.

## Важный момент про данные

GymStats работает локально. Интернет для обычной работы приложения не нужен.

Перед удалением приложения, сменой телефона или сбросом устройства обязательно создай резервную копию через раздел **Резервная копия**.

Приложение рассчитано на Android API 24+ и подходит для Android 13 (API 33).

## Где искать APK

Прямой путь на GitHub:

**Actions → успешный GymStats CI → Artifacts → GymStats-Android → скачать ZIP → распаковать → установить APK на телефон.**

Если в конкретном запуске блока **Artifacts** нет, значит Android-сборка этого запуска не создала APK. Выбери другой запуск со статусом **Success**, где присутствует `GymStats-Android`.
