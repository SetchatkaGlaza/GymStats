# GymStats

Offline-first трекер силовых тренировок и антропометрии на .NET MAUI.

## Возможности

- тренировки с нуля и по шаблонам;
- подходы: вес, повторения, RPE, темп;
- предыдущий результат упражнения прямо при вводе подхода;
- база упражнений с фильтрами по мышечной группе, оборудованию и движению;
- пользовательские упражнения;
- цели шаблонов: подходы, повторы, вес и RPE;
- аналитика тренировок, тоннажа и среднего RPE;
- графики прогресса по упражнению и объёмам;
- графики антропометрии с выбором показателя;
- замеры веса, груди, талии, бёдер, бицепса, бедра, икры и шеи;
- фото и видео прогресса с локальным хранением;
- полный ZIP-бэкап истории и медиа;
- тёмная тема через системную тему;
- Android, iOS, Mac Catalyst и Windows.

## Стек

- .NET 10
- .NET MAUI
- C#
- Entity Framework Core 10
- SQLite
- CommunityToolkit.Mvvm
- xUnit

Данные хранятся локально в SQLite. Интернет приложению для обычной работы не требуется.

## Запуск

1. Установить Visual Studio 2026 с workload .NET MAUI.
2. Открыть GymStats.slnx.
3. Выбрать Android Emulator или Windows Machine.
4. Запустить проект GymStats.

Для iOS потребуется Mac с установленным Xcode и настроенной Apple signing-инфраструктурой.

## Тесты

Запуск: dotnet test GymStats.Tests/GymStats.Tests.csproj

CI дополнительно проверяет unit-тесты и Release-сборки Android, Windows и iOS без подписи.

## Данные

Перед сменой устройства используй раздел Резервная копия. ZIP содержит JSON со структурой данных и найденные локальные фото/видео.

## Архитектура

- Models — сущности локальной БД;
- Data — SQLite/EF Core и безопасное обновление локальной схемы;
- ViewModels — состояние экранов и команды;
- Services — аналитика, медиа, бэкап и графики;
- Resources/Styles — единая визуальная система.

Приложение спроектировано так, чтобы позже можно было добавить синхронизацию без зависимости текущего офлайн-режима от облака.

## Установка на Android-телефон

### Вариант 1 — готовый APK из GitHub Actions

1. Открой страницу Actions репозитория.
2. Открой последний успешный запуск CI.
3. Внизу страницы найди раздел **Artifacts**.
4. Скачай архив **GymStats-Android**.
5. Распакуй ZIP — внутри будет APK.
6. Передай APK на телефон (USB, Telegram, Google Drive или другим способом).
7. Открой APK на телефоне и подтверди установку. Если Android попросит разрешение на установку из неизвестного источника, разреши его для приложения, через которое открываешь APK.
8. После установки запусти GymStats.

### Вариант 2 — через USB с компьютера

1. Включи на телефоне **Для разработчиков** и **Отладку по USB**.
2. Подключи телефон кабелем и разреши отладку для этого компьютера.
3. Установи APK командой `adb install GymStats-*.apk`.
4. После установки приложение появится среди обычных приложений.

Приложение рассчитано на Android API 24+ и подходит для Android 13 (API 33). Для обычной работы интернет не требуется.

> **Важно:** APK из CI — это Release-сборка приложения. Если Android блокирует установку, проверь разрешение **«Установка неизвестных приложений»** для используемого файлового менеджера или браузера.
